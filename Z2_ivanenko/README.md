# WEBTE1 – Zadanie 2: Obedové menu v okolí fakulty

**Autor:** Denys Ivanenko

**Krúžok:** pondelok o 9:00

**Web na školskom serveri:** [Obedové menu](https://webte1.fei.stuba.sk/~xivanenko/Z2_ivanenko/index.html)

Web zobrazuje obedové menu troch prevádzok v okolí FEI STU. Návštevník si môže vybrať deň, zobraziť celý týždeň a filtrovať prevádzky. Údaje sa načítavajú z lokálnych HTML kópií a ukladajú sa v prehliadači, aby sa počas aktuálneho dňa nemuseli načítavať znova. Tlačidlá umožňujú menu znovu načítať a vymazať uložené dáta.
